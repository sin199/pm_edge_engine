# Code of Conduct

## Our standard

This project is small and early, but contributions and discussions should still stay professional and useful.

Expected behavior:

- be respectful and direct
- focus on evidence, repro steps, and clear technical reasoning
- assume good faith unless there is strong evidence otherwise
- keep criticism specific to code, behavior, or process

Unacceptable behavior:

- harassment, abuse, or personal attacks
- spam, trolling, or bad-faith issue filing
- sharing private credentials, secrets, or personal information
- misleading bug reports or intentionally low-signal noise

## Scope

This applies to:

- issues
- pull requests
- discussions
- other project communication spaces

## Enforcement

The maintainer may remove comments, close threads, or block contributors whose behavior makes the project harder to maintain safely and productively.

## Reporting

If something needs maintainer attention, open a GitHub discussion or issue if appropriate. For sensitive disclosures, use the process in [SECURITY.md](./SECURITY.md).
